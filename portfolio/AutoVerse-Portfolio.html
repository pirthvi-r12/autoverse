Admin panel

Auth Login & security

  • POST /api/admin/login
    ADMIN_DEMO_* → signed HTTP-only cookie.
  • POST /api/admin/logout
    Clear session.
  • middleware.ts
    Protects /admin/* and /api/admin/*.

Cars Inventory CRUD

  • upsertCar
    Create/update MOCK_CARS, slug, images, revalidate paths.
  • setCarStatus / deleteCar / markCarSoldAction
    available | reserved | sold.
  • CarForm
    Full spec fields, featured, status, images_json.
  • CarImageManager
    dnd-kit reorder, cover, upload, delete.
  • POST /api/admin/car-images
    Auth; max 8MB → public/uploads/cars/{id}/.

Inspections

  • InspectionsAdminTable
    Search, status tabs, counts, CSV export.
  • changeInspectionStatus
    pending → confirmed → in_progress → completed / cancelled.
  • InspectionChecklistForm + finalizeInspectionReport
    Scores, remarks → report token in MOCK_REPORTS.
  • createCarFromInspectionAction
    Draft listing from booking data.

Leads & PDF

  • getLeads() / /admin/leads
    Contact, newsletter, inspection leads.
  • GET /api/reports/[token]/pdf
    React-PDF inspection download.
  • /report/[token]
    Customer report page + ReportActions.
